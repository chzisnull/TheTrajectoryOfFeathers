## ✨ 为什么创建羽迹？

羽毛球视频分析面临高速球体、运动模糊、遮挡和帧率有限等挑战。羽迹希望结合计算机视觉、运动学与人工智能，将比赛或训练视频转化为对运动员和教练有用的参考信息。

**项目状态：规划中。** 仓库目前只有文档，尚未实现任何分析功能。

## 🎯 拟实现的能力

- **羽毛球追踪：** 探索多帧追踪及模糊、遮挡情况下的轨迹重建；TrackNet 和卡尔曼滤波是候选方法。
- **运动与步法：** 探索姿态估计和运动员追踪，研究移动、场地覆盖、反应及身体协调；YOLOv8-Pose 和 ByteTrack 是候选方案。
- **球场标定与测量：** 研究将图像坐标映射至标准球场尺寸（13.4 米 × 6.1 米），在视频和标定条件允许时估计移动距离与速度。球速和力量运用相关信息是长期研究目标。
- **AI 教练与报告：** 探索结构化分析、训练建议、视觉报告和带标注的视频。

以上均为目标，并非已有功能或确定的技术架构。视频测量受到机位、标定、帧率等条件影响，不能假设单目视频能够准确测出真实力量或球速；估计结果需要验证并说明不确定性。

候选库和模型各有许可与使用条款，使用或分发前需要分别核查。本仓库的 MIT 许可证不会自动适用于第三方依赖或模型权重。
